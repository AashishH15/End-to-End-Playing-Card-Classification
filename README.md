# End-to-End Playing Card Classification using a Feedforward and Sequential Convolutional Neural Network

This project focuses on image classification of playing cards using a FNN and Sequential CNN.

**Notebooks:**

* **Helper Notebooks:**
  * `load_data_demo.ipynb`: Demonstrates loading and visualizing the preprocessed dataset. Code to display sample images with their corresponding labels, for the data structure and content.
  * `preprocess.ipynb`: Data loading and preprocessing steps. This notebook loads the dataset using `ImageFolder`, and creates numerical labels to card names.

* **Models:**
  * `FeedforwardNN.ipynb`: Baseline model for neural network.
  * `SequentialConvolutionalNN.ipynb`: More advanced model.
